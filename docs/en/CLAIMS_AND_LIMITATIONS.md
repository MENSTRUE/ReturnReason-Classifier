# Claim Boundaries and Limitations

> Research prototype; not production-ready.

Allowed claims: working local end-to-end NLP prototype, genuine IndoBERT checkpoint inference, FastAPI integration, React dashboard, five uncalibrated class scores, mandatory human confirmation, and explicitly scoped synthetic metrics.

Prohibited claims: 95% real-customer accuracy; reliable negation understanding; trained OOD detector; multi-label prediction; calibrated probability; autonomous refunds; fraud prevention; production readiness; independent human-labeled test results.

`SUGGESTED` is a provisional top-softmax routing policy (threshold 0.65), not approval.

`REVIEW` is below threshold, yet **every** prediction requires human review.

Threshold is not a validated safety boundary.

New evidence must update root README, both language docs and AGENTS together.

Do not compare differently labeled/supported validation and external results as equivalent benchmarks.
